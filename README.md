# Sipeng Sun's academic homepage

A responsive, dependency-free academic homepage for GitHub Pages. All page content and styles are in `index.html`.

## Publish

Repository: `SunnyMeow12/SunnyMeow12.github.io`.

In **Settings → Pages**, select **Deploy from a branch**, then **main** and **/(root)**. The homepage will be available at https://sunnymeow12.github.io/ after deployment succeeds.

## Edit

Edit `index.html` directly in GitHub or locally and commit to `main`. There is no build step, JavaScript dependency, tracking, or contact-form backend. Email links open the visitor's mail app.
